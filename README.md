# Sudharsan Ramankulath — Executive Portfolio

Personal portfolio website built from the Stitch design **Sudharsan Ramankulath - Executive Portfolio**.

## Preview locally

```bash
python3 -m http.server 5173
```

Then open [http://localhost:5173](http://localhost:5173).

## Structure

- `index.html` — full single-page portfolio
- `assets/portrait.png` — hero portrait from the Stitch project
